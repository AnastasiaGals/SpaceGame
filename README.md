# SpaceGame
A basic moon-lander-like game with small-planets in Lua Love.

# Instructions
Built with the assumption of qwerty keyboards. Select a level with A and D, start using W. When in a level press W to accelerate forward and S to decelerate at a slower rate. Use A and D to add spin to your spacecraft.

Try to score a high score by not crashing your spacecraft and not running out of oxygen (the blue bar) to regain oxygen land on a planet and stay there for a moment.

# Dependencies
This game is built with [Show](https://github.com/challacade/udemy-love2d/blob/master/show.lua) for easily writing high-scores to text files, and [Push](https://github.com/Ulydev/push/blob/master/push.lua) for screen scaling.
